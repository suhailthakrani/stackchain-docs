---
title: Page generator
description: Generate a shared page widget with stackchain make page.
---

```bash
dart run stackchain make page onboarding
```

## Output

```text
lib/shared/pages/onboarding_page.dart
```

StatelessWidget scaffold. After generation, stackchain auto-runs sync with analyze skipped.

## Options

```bash
dart run stackchain make page checkout --overwrite
dart run stackchain make page checkout -V title=Checkout
```
