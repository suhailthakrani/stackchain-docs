---
title: AutoRoute
description: AutoRoute configuration and code generation with stackchain.
---

## YAML

```yaml
stackchain:
  routing: auto_route
```

## Dependencies

Infers `auto_route` and `auto_route_generator` (dev). After scaffold:

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
```

## Notes

Keep generated AutoRoute outputs out of hand-edits; extend via stackchain regions and your annotated route definitions as generated by templates.
