---
title: GetX Routing
description: GetX navigation generated when routing is set to getx.
---

## YAML

```yaml
stackchain:
  state_management: getx
  routing: getx
  di: getx
```

Smart default: omitting `routing` while state is `getx` selects GetX routing.

Pairs naturally with the `getx_mvc` preset and feature `bindings/`.
