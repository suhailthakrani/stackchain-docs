---
title: Networking overview
description: Dio and HTTP networking stacks generated by stackchain.
---

```yaml
stackchain:
  network: dio
```

| Value | Packages |
| --- | --- |
| `dio` (default) | `dio`, `pretty_dio_logger` + interceptors |
| `http` | `http` + simpler API client |

Both feed the repository pattern inside feature `data/` layers.
