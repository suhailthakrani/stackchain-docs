# stackchain docs

Official documentation for **[stackchain](https://pub.dev/packages/stackchain)** — config-driven Flutter scaffolding that evolves with your app.

Built with [Astro](https://astro.build) + [Starlight](https://starlight.astro.build).

## Requirements

- Node.js 20+

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Build

```bash
npm run build
```

Static output is written to `dist/`.

## Preview

```bash
npm run preview
```

## Project structure

```text
src/
  assets/           # Logo + SVG diagrams
  components/       # Starlight overrides (Footer)
  content/docs/     # Documentation pages (MD/MDX)
  styles/           # Brand theme
public/             # Favicon, OG image
astro.config.mjs    # Site + sidebar + SEO
```
